# ShipList

**给灵感一个落脚点，把想做的事慢慢做出来。**

[English](https://github.com/chloeh-1379/shiplist/blob/main/README.md) · 简体中文

一个总在脑海里打转的 App、一个周末想试试的小实验、一个「要是有就好了」的工具。
先记下来，再往前推进一点。ShipList 陪你把想法变成真正发布的作品。

## 从「有个想法」到「已经上线」

- **先抓住灵感。** 只写一个标题就能保存。等想清楚了，再补简介、笔记、参考链接和标签。
- **看清自己在做什么。** 用卡片浏览所有项目，按进度筛选，或搜索标题、笔记和标签。给更想做的项目加上优先级星标。
- **让下一步更明确。** 点开一个想法，把计划、参考资料和进展日志放在一起。笔记支持 Markdown，可以用标题和列表整理思路。
- **留下发布的足迹。** 从 **Idea（想法）→ Planned（已计划）→ Building（开发中）**，到 **Shipped（代码已发布）**、**Released（已上线）** 或 **Sold（已出售）**。附上仓库、网站或商店链接，以后随时回看。
- **也允许改变主意。** 暂时不做，就设为 **Parked（搁置）**；决定结束，就设为 **Stopped（停止）**。之前的笔记和进展仍然保留。
- **把想法带走。** 导出 Markdown，方便阅读和分享；导出完整 JSON，方便备份。所有想法都保存在你选的本地文件夹里。

## 开始使用

先安装 [Node.js](https://nodejs.org/) 18 或更高版本，然后在终端运行：

```bash
git clone https://github.com/chloeh-1379/shiplist.git
cd shiplist
node server.js
```

在浏览器打开 **[localhost:4520](http://127.0.0.1:4520)**，点击 **New idea**，就能记下第一个想法。
不需要安装额外依赖，也不需要注册账号。使用期间保持终端运行即可。

macOS 用户也可以在下载好的项目文件夹里双击 **start.command**，启动服务并打开页面。

## 按自己的节奏来

**从小处开始。** 一个名字就够了。选择未来想发布成什么：App、网站、GitHub 仓库、命令行工具、代码库，或者其他形式。细节可以边做边补。

**选一个自己的文件夹。** 打开 **Settings**，查看或修改数据保存位置。默认是 `~/ShipList/ideas.json`，像备份其他重要文件一样备份它就好。如果新文件夹里还没有想法数据，ShipList 会把现有想法复制过去。

**分享最近在做的事。** 点击顶部 **Export**，选择 **Markdown** 导出可读的项目合集，或选择 **JSON** 导出完整数据副本。

几个顺手的快捷键：按 **/** 搜索，按 **Esc** 关闭弹窗或退出编辑，编辑时按 **⌘/Ctrl + Enter** 保存。

## 聊出灵感，也能顺手记下

给兼容的 AI 编程助手安装随项目提供的 [ShipList skill](./skills/shiplist/SKILL.md) 后，可以在聊天时直接让它记录想法：

> 「把这个想法记到 ShipList，带上我们刚讨论的第一版范围。」
>
> 「把 Pocket Planet 改成开发中，记一下今天的进展。」
>
> 「已经发布了，补上仓库链接，更新状态。」

助手和界面使用同一份本地记录。你也可以直接导出 Markdown，把想法合集放进对话里一起讨论。

## 使用前知道这些就够了

ShipList 在你自己的电脑上运行。准备好 Node.js 和项目后即可离线使用，没有内置的云同步或团队账号。当前应用界面为英文，本说明同时提供 [English](https://github.com/chloeh-1379/shiplist/blob/main/README.md) 版本。
